# Clone Medium - Página Inicial

Recriação da página inicial do Medium em português, feita com HTML e CSS puros
para praticar estruturação de página, posicionamento e estilização.

🔗 **Demo:** https://Laura-AndradeWeb.github.io/medium-clone/

## Tecnologias

- HTML5
- CSS3

## O que foi praticado

- Estrutura da página em blocos: cabeçalho, destaque, tendências e rodapé
- Cabeçalho fixo no topo com position: fixed
- Menu horizontal com float e efeitos de: hover
- Container centralizado com margin: 0 auto
- Imagem de fundo na seção de destaque com background
- Itens de tendência em colunas com float, usando clearfix (::after)
- Numeração sobre os itens com position: absolute
- Ícones aplicados como imagem de fundo (background: url(...))
- Botões arredondados com border-radius
- Tipografia com fonte serifada (Times New Roman) e letter-spacing
